# 02 — critical review

Use a fresh review pass. Read the repository state and the output of Pass A.

Treat Pass A's recommendation as provisional. Test whether it is the best allocation of the next bounded research cycle.

Check specifically for:

- path dependence from the current backbone or protocol;
- a neglected branch that has higher information value;
- a simpler experiment that dominates additional reading;
- a claim whose wording makes it too easy to preserve;
- confusion between explanatory levels;
- a missing coordinate or variable;
- protocol overhead that no longer changes conclusions;
- evidence that the program should reconstruct or revise rather than expand.

Return:

1. the strongest criticism of Pass A's recommendation;
2. the evidence supporting that criticism;
3. one concrete alternative next move;
4. the observation that would make the criticism no longer persuasive.

If Pass A survives the review, say why. Do not invent disagreement merely to make the passes look independent.
