# Research router

Default to the cheapest procedure that can answer the question responsibly.

## Lane 1 — fast

Use ordinary native research and synthesis when the task is factual, explanatory, or low-conflation.

Stop when the answer is adequate for the decision.

Escalate only if the fast pass exposes a consequential unresolved rival, missing coordinate, objective dependence, boundary dependence, or verification problem.

## Lane 2 — escalation

Use a lightweight anti-collapse pass when multiple mechanisms, objectives, explanatory levels, system boundaries, or verification regimes may be bundled.

Required output:

- native question;
- live alternatives;
- what decision changes if they differ;
- cheapest discriminator.

Stop once that ambiguity is resolved. Do not open a full round by default.

## Lane 3 — deep

Use `.agents/skills/anti-collapse-research/SKILL.md` only if at least one is true:

- a substantive claim can fail in a way that changes belief;
- a specific missing coordinate/observable blocks formulation;
- a consequential decision depends on live rival models;
- a cross-domain generalization is being considered for promotion.

Before opening the cycle, write:

```text
target:
strongest_rival:
discriminating_consequence:
verifier:
decision_changed_if_A:
decision_changed_if_B:
```

If these cannot be filled honestly, the deep lane is not earned.

## Promotion rule

Explore widely and cheaply. Promote narrowly and expensively.

> Velocity happens before promotion, not instead of verification.

A repaired claim is a new claim, not survival of a failed predecessor.

See `fieldwork/acceleration.md` for the full operating model.
