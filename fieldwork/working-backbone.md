# working backbone

Status: **working navigational hypothesis — not seed revision, not canon**  
Origin: source-closed reconstruction 001; explicitly accepted as sound enough to continue crawling from.

> A bounded system cannot realize, observe, or represent every possibility.  
> Interfaces, constraints, dynamics, and history shape what becomes accessible.  
> Any useful equivalence is indexed by what must be preserved.  
> Structure may be represented, enacted, selected, or distributed.  
> Prediction, intervention, and control require different forms of access.  
> Learning requires that consequential error survive a channel and reach something that can revise.

## How to use this

This backbone is allowed to organize **integration and probe design**. It is not allowed to organize blind search.

Blind scouts still receive native questions without this file, the seed, or current collision summaries. A result does not count as support merely because it can be paraphrased into the backbone's vocabulary.

## Current pressure points

The backbone is intentionally weaker than the frozen seed. The next phase should try to break or sharpen it by asking, among other things:

- whether accessibility can be characterized without assuming a pre-given state space;
- whether equivalence must always be indexed by a task / transformation / verifier;
- when local guarantees compose and when system-level guarantees require new structure;
- whether contact can be made reliable without a traceability chain;
- whether system boundaries can be operation-relative without becoming arbitrary;
- when a system changes the constraints that will govern its own future states.

## Promotion rule

Do not edit this backbone after every interesting source. Changes require either:

1. an answered discriminating probe that survives an independent verifier; or
2. heterogeneous survival of the same distinction across genuinely different mechanisms.

The frozen seed remains the historical object under test. This file is only the current map for deciding where stronger tests are worth spending.
