# working backbone — status after first falsification pass

Status: **test status only — not a rewritten backbone, not seed revision**

The original working backbone remains unchanged as the object under test. This note records what the probes currently say about each clause.

## Clause status

1. **Boundedness** — failed as written. A finite bounded system can completely represent, observe, and visit a finite possibility space. The missing premise is a relative capacity relation between system and relevant possibility space.

2. **Accessibility** — bad discriminator as written. Any reachable subset can be encoded after the fact as a constraint or transition relation. Explanatory mechanisms need independent, counterfactual content.

3. **Equivalence** — bad discriminator as written. Every equivalence relation can be represented as equality of quotient-class labels. A preservation criterion must be fixed independently enough that alternative partitions could fail it.

4. **Structure** — currently functions as a taxonomy / anti-collapse reminder rather than a substantive general law. `May be represented, enacted, selected, or distributed` is too permissive to score like a universal claim.

5. **Prediction / intervention / control** — still live. Existing work supports their separation, but `different forms of access` still needs a direct hostile probe.

6. **Learning / error** — ambiguous. Oja-style unsupervised learning requires no explicit target mismatch, while broad optimization language can reinterpret the update as implicit error. The word `error` is not yet discriminating enough.

## Candidate repairs — quarantined

Do not promote these yet.

- Boundedness: `Selectivity becomes unavoidable when the relevant possibility space exceeds the system's capacity for realization, observation, or representation.`
- Accessibility: `Accessibility should be explained by independently specified mechanisms that rule out alternative reachability patterns before the outcome is known.`
- Equivalence: `A useful equivalence needs a preservation criterion specified independently enough that alternative partitions could fail it.`

The next reconstruction should decide whether these survive heterogeneous contact. Until then, the failures remain visible instead of being silently patched.
