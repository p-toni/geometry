# branch — levels of explanation

Role: **hostile / cross-cutting**  
Status: open

## Native question

When do explanations at computational, algorithmic/representational, mechanistic, and physical levels answer genuinely different questions about the same system?

## Native vocabulary / literatures

Computational level, representation and algorithm, mechanism, hardware implementation, abstraction barriers, reduction, multiple realization.

## Competing explanations to preserve

- relatively independent levels of analysis;
- integrated multi-level explanation in which constraints run both directions;
- reductionist accounts that treat higher levels as dispensable;
- ecological/enactive accounts that reject some representational assumptions built into classical computational framing.

## What would make this branch matter

Evidence that one cross-domain vocabulary can become misleading if it silently moves claims from one explanatory level to another or treats a functional regularity as if it specified mechanism.

## Stop condition

Pause when the branch can state concrete examples where two claims are both valid but answer different levels, and at least one case where level independence fails.
