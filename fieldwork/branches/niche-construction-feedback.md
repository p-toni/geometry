# branch — niche construction feedback

Role: **alien / cross-cutting**  
Status: open

## Native question

How can organisms modify environmental conditions in ways that change the selection pressures acting on themselves, descendants, and other species?

## Why this branch exists

Niche-construction work provides a native biological case where an adaptive system does not merely search a fixed environment: activity changes the future selective environment and can create ecological inheritance.

## Native vocabulary / literatures

Niche construction, ecological inheritance, organism-environment feedback, source of selection, ecosystem engineering, gene-culture coevolution.

## Competing explanations to preserve

- niche construction as a distinct evolutionary process;
- environmental modification as a background condition already representable inside standard evolutionary theory;
- adaptive versus incidental environmental modification;
- short-lived feedback versus inherited changes in selective environment.

## What would make this branch matter

Evidence that the effective state/search landscape is endogenously modified by the system's own behavior, with later possibilities and payoffs depending on those changes.

## Stop condition

Pause when additional cases add examples without sharpening the causal distinction between modifying an environment and modifying the selection pressures that govern future trajectories.
