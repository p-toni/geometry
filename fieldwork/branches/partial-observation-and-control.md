# branch — partial observation and control

Role: **alien / cross-cutting**  
Status: open

## Native question

What properties of a dynamical system can be inferred from limited measurements, and which state changes can be produced from limited control inputs?

## Why this branch exists

Control theory separates what can be observed from what can be controlled. This gives a formal language for interfaces with systems whose full internal state is not directly available.

## Native vocabulary / literatures

State-space models, observability, controllability, reachability, state estimation, realization, feedback, Kalman systems theory.

## Competing explanations to preserve

- complete-state reconstruction;
- control without full reconstruction;
- structural vs numerical observability/controllability;
- nonlinear cases where linear tests do not transfer.

## What would make this branch matter to the seed

A rigorous distinction between access, inference, prediction, and intervention under partial observation. It may show that useful control does not require carrying or reconstructing the whole state.

## Stop condition

Pause if the research leaves the native control problem and becomes generic metaphor about interfaces or agency.
