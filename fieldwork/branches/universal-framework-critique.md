# branch — universal framework critique

Role: **hostile**  
Status: open

## Native question

When does a formal framework become so permissive that redescribing a system inside it stops explaining why the system behaves as it does?

## Why this branch exists

Several candidate frameworks in our frontier make very broad scope claims. A hostile branch is needed that studies the difference between a modeling language applying to many systems and a principle discriminating mechanisms, predictions, or interventions.

## Native vocabulary / literatures

Scope, explanatory power, model class, unfalsifiability, overgeneration, representational equivalence, free-energy principle, Markov blankets, dynamical hypothesis, computational metaphor, process theory.

## Competing explanations to preserve

- a very general formalism can unify phenomena and generate useful constraints;
- broad applicability can become trivial if almost every system can be encoded;
- a framework may be useful as a modeling language without being a causal/explanatory principle;
- explanatory value can come from added process assumptions rather than the universal formal shell.

## What would make this branch matter

A reusable discriminator between “can be described as” and “is explained by,” especially for claims of scale-free or universal principles.

## Stop condition

Pause when critiques become purely rhetorical. Continue only when a source identifies a specific missing mechanism, failure condition, or empirical consequence.
