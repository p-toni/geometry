# branch — distributed knowing

Role: **cross-cutting**  
Status: open

## Native question

Under what conditions can a distributed system produce a reliable result that no individual component can reconstruct or survey end-to-end?

## Candidate domains

Formal mathematics, scientific collaborations, theorem proving, multi-agent AI, organizations, markets, distributed systems, collective intelligence.

## Distinctions to protect

- truth vs verification;
- verification vs understanding;
- local understanding vs system-level reliability;
- decomposition vs mere scale;
- architectural control vs cognitive control by an individual;
- provenance vs ownership.

## Initial pressure

The 2026 OpenAI Navier–Stokes result is a concrete case because the reported search used on the order of 10,000 concurrent agents and a separate formalization/verification phase. Treat this as a case to study, not proof of any thesis.

## What would make this branch matter

A defensible account of where epistemic responsibility, error integration, and system boundaries live when no participant contains the whole result.
