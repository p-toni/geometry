# branch — unprestatable phase space

Role: **hostile / alien**  
Status: open

## Native question

Are there domains in which novelty changes the scientifically relevant variables themselves, so that inquiry cannot be represented as traversal of a fully prestated state space?

## Why this branch exists

The research operating model uses “state-space exploration” as a metaphor for broad search. Evolutionary theory offers a direct challenge: some authors argue that biological novelty changes the phase space itself, including the relevant observables and niches.

## Native vocabulary / literatures

Phase space, observables, novelty, enablement, evolutionary possibility, changing boundary conditions, extended criticality, open-ended evolution.

## Competing explanations to preserve

- evolutionary novelty requires genuinely changing / unprestatable phase spaces;
- a sufficiently expressive latent state space could in principle precontain later novelty;
- practical model expansion is enough even if metaphysical precontainment remains undecidable;
- local fixed-state models can be useful while global open-ended evolution remains non-prestatable.

## What would make this branch matter

Evidence or argument that forces the protocol to distinguish “searching unknown states” from “inventing new coordinates / observables” rather than treating all novelty as unexplored territory in a fixed frontier.

## Stop condition

Pause if the debate becomes purely metaphysical and no operational difference for research design can be extracted.
