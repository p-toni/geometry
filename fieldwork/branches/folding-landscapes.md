# branch — folding landscapes

Role: **alien**  
Status: open

## Native question

How do proteins reach functional conformations quickly and reliably despite an astronomically large space of possible conformations?

## Why this branch exists

Protein biophysics contains a mature state-space problem in which exhaustive search is not the mechanism. Energy-landscape theory explains how physical energetics and evolutionary sequence selection bias trajectories toward foldable regions.

## Native vocabulary / literatures

Energy landscapes, folding funnels, frustration, native state, kinetic traps, transition ensembles, folding pathways, sequence selection.

## Competing explanations to preserve

- funneled energy-landscape accounts;
- pathway/intermediate accounts where particular routes matter;
- chaperone-assisted cellular folding;
- intrinsically disordered and multi-state proteins that resist a single-native-funnel picture.

## What would make this branch matter to the seed

If large state spaces become tractable because transition probabilities and energetic accessibility are structured before any learner searches them, then “exploration” cannot be modeled as uniform traversal of a fixed possibility space.

## Stop condition

Pause when the branch only repeats the funnel metaphor without sharpening what creates the bias, when it fails, or how path accessibility differs from state count.
