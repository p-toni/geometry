# branch — collective choice without comparison

Role: **alien / cross-cutting**  
Status: open

## Native question

How can a group select one high-quality option when no member compares the full set of alternatives or possesses a global representation of the decision problem?

## Why this branch exists

Social-insect decision making provides experimentally tractable cases where local recruitment, attrition, inhibition, and quorum mechanisms produce a colony-level choice without centralized comparison.

## Native vocabulary / literatures

Recruitment, waggle dance, quorum sensing, cross-inhibition, decentralized consensus, scout dynamics, collective decision making.

## Competing explanations to preserve

- self-organized recruitment/attrition dynamics;
- quorum-based commitment;
- cross-inhibition between alternatives;
- individual comparison models;
- cases where informed minorities steer groups without explicit signaling.

## What would make this branch matter to the seed

If a system can discriminate among alternatives without any component carrying the comparison, then global choice, global representation, and global understanding must remain separate properties.

## Stop condition

Pause when additional cases only reproduce the same local-recruitment-to-quorum architecture without changing which information is local, how errors are corrected, or where the decision boundary lies.
