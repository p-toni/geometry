# branch — predictive state reconstruction

Role: **alien / cross-cutting**  
Status: open

## Native question

What is the smallest state description that preserves all information needed to predict the future statistics of a stochastic process?

## Why this branch exists

Computational mechanics attacks prediction without beginning from cognitive or geometric language. It defines state through predictive equivalence among histories and asks when a representation is sufficient, minimal, and reconstructable from observations.

## Native vocabulary / literatures

Causal states, predictive equivalence, ε-machines, statistical complexity, sufficient statistics, stochastic processes, state reconstruction.

## Competing explanations to preserve

- causal-state / ε-machine reconstruction;
- conventional hidden-state models;
- task-specific sufficient statistics;
- representations optimized for control rather than prediction;
- cases where nonstationarity or limited data defeats a stable state decomposition.

## What would make this branch matter to the seed

If useful state is defined by equivalence of future distributions rather than similarity of present or past configurations, then a cut can be licensed by counterfactual predictive consequences rather than by visible invariance.

## Stop condition

Pause when additional work only restates ε-machine minimality without changing the scope conditions, reconstruction assumptions, or relationship between predictive and causal state.
