# branch — learning without explicit error

Role: **hostile / cross-cutting**  
Status: open

## Native question

Can a system undergo technically meaningful learning without receiving an explicit error signal, target mismatch, reward, or teacher label?

## Why this branch exists

The working backbone currently says learning requires consequential error to survive a channel and reach something that can revise. Unsupervised local learning rules are a direct hostile test of whether `error` is genuinely necessary or merely one implementation of adaptive feedback.

## Native vocabulary / literatures

Hebbian learning, Oja's rule, unsupervised learning, self-organization, synaptic plasticity, principal-component extraction, local learning rules.

## Competing explanations to preserve

- learning requires explicit error / reward / mismatch information;
- local correlation-driven adaptation is learning without an error channel;
- apparent error-free learning implements an implicit optimization discrepancy, so the distinction is representational rather than mechanistic;
- `learning` itself may be too broad and should be indexed by what changes and what performance criterion is preserved.

## What would make this branch matter

A clean example that is ordinarily called learning, exhibits durable adaptive change, and has no operationally identifiable error signal would force the backbone's final clause to weaken or replace `error` with a broader term.

## Stop condition

Pause if the debate reduces entirely to redefining `error` after the fact. At that point the useful result is that the term lacks discriminating power.
