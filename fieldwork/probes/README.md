# probes

A probe is how a live collision becomes answerable.

Do not create a probe merely to make the workflow look scientific. A useful probe distinguishes live alternatives or forces a map to pay for a claim.

## Valid forms of contact

- empirical intervention;
- formal proof or verification;
- simulation with discriminating outputs;
- historical/archival check;
- behavioral prediction;
- shipped artifact with observable consequence;
- external decision whose result can return;
- another explicit constraint that the map cannot negotiate with.

## Rule

Prefer the cheapest discriminating probe.
