> [thesis|thesis]
> A tool without constraints is not liberating. It is unfinished.

## Frame

Infinite possibility often arrives disguised as freedom.

A blank canvas. An endless feed. A thousand settings. A model that can answer anything.

At first, it feels powerful. Then the debt appears: before doing the work, the user has to invent the frame.

That is the hidden cost of many digital tools. They do not only ask for attention. They ask for orientation. They hand you a possibility space and quietly make you responsible for its rules.

Digital minimalism was an early response: choose less, turn things off, remove the unnecessary, reclaim attention from systems designed to capture it.

That instinct is right, but incomplete.

The deeper question is not only how to use less technology. It is how to design tools that return agency instead of consuming it.

## Claim

Good tools have edges.

A haiku has edges. A piano has edges. A camera lens has edges. The OP-1 has edges. A command line has edges.

Those constraints do not reduce expression. They make expression possible. They give the hand something to learn, the mind something to push against, and the user a way to begin.

> [aside|design rule]
> A good constraint is not a wall. It is a grip.

## Operator

Edges do three jobs.

1. **They narrow the field.** The user can start without first designing the situation.
2. **They make feedback legible.** Action and result stay close enough to learn from.
3. **They let skill accumulate.** Repetition compounds because the instrument has a stable shape.

The best tools do not hide complexity. They make complexity playable.

This is what teenage.engineering understands better than most software companies: maximum function, minimum form is not minimalism as decoration. It is a theory of agency. Every visible element must earn its place. Every control should invite use. The interface should feel less like a maze and more like an instrument.

Bad software does the opposite. It treats possibility as a feature: more menus, more notifications, more modes, more surfaces, more things to manage. It calls this power, but much of it is deferred design work passed to the user.

## AI makes this sharper

When software becomes generative, the possibility space expands faster than ordinary interface patterns can hold.

A panel of controls is no longer enough. A chat box is no longer enough. A blank prompt is often just a more polite blank canvas.

Without frames, evals, loops, memory, taste, and boundaries, the user is left steering fog.

So AI tools need stronger edges, not weaker ones:

- task frames instead of infinite prompting
- visible assumptions instead of fluent certainty
- recoverable traces instead of disposable outputs
- human-owned taste instead of hidden delegation
- evaluation loops instead of demo confidence

## Test

A tool is working when the user can feel the relationship between intention and result.

A tool is failing when the user must spend more energy managing the possibility space than acting inside it.

The future of good tools will not be defined by how much they can generate. It will be defined by how well they preserve agency inside abundance.

The point is not to make technology smaller.

The point is to make it holdable.

Tools need edges because humans do.
