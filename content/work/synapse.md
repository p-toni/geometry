Synapse asks how agent systems earn trust when their behavior is otherwise too slippery to inspect.

The answer is determinism where possible, replay where necessary, and explicit evidence boundaries before any authority decision.

> [thesis|standard]
> If an agent changed something, the system should be able to show what happened, under which contract, and whether the evidence is proof or projection.
