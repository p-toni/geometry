Codex Fieldwork is the working method behind this site.

The artifact is not only the code. It is the practice: read the field, recover lost materials, decide what deserves a node, tune the visual language, test the browser, commit, push, and deploy.

> [thesis|practice]
> The useful agent is not a replacement author. It is an inspectable build loop for judgment that still belongs to the human.
